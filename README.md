# Matrix Project - библиотека для работы с матрицами

Реализация библиотеки для работы с матрицами на языке C: создание, удаление,
арифметические операции, транспонирование, вычисление определителя и обратной
матрицы. Проект выполнен в рамках учебной программы School 21. Формулировки задания удалены.

## Возможности

Библиотека `s21_matrix.a` предоставляет:

- Создание и удаление матриц (`s21_create_matrix`, `s21_remove_matrix`)
- Сравнение матриц (`s21_eq_matrix`)
- Сложение и вычитание (`s21_sum_matrix`, `s21_sub_matrix`)
- Умножение матрицы на число (`s21_mult_number`)
- Умножение матриц (`s21_mult_matrix`)
- Транспонирование (`s21_transpose`)
- Вычисление матрицы алгебраических дополнений (`s21_calc_complements`)
- Определитель (`s21_determinant`)
- Обратная матрица (`s21_inverse_matrix`)

Все функции возвращают код ошибки.

| Код | Константа              | Значение             |
|-----|------------------------|----------------------|
| `0` | `OK`                   | Успех                |
| `1` | `Error_Invalid_Matrix` | Некорректная матрица |
| `2` | `Error_Calculation`    | Ошибка вычислений    |

## Сборка

```make
make                # clean + сборка библиотеки + запуск тестов
make s21_matrix.a   # собрать только статическую библиотеку
make test           # собрать и запустить unit-тесты
make rebild         # полная пересборка (clean + сборка + тесты)
make clean          # удалить артефакты сборки и сгенерированные папки
make valgrind       # Проверить программу на утечки памяти
make gcov_report    # Сформировать отчет покрытия тестов
make style          # Проверить код на соответствие Google-style
make fix-style      # Исправить код на соответствие Google-style
```

## Использование

Подключите заголовочный файл `s21_matrix.h` и слинкуйте статическую библиотеку.

```C
#include "s21_matrix.h"

int main(void) {
    //создание матрицы
    const int rows = 2;
    const int columns = 2;

    matrix_t A = {NULL, 0, 0};
    s21_create_matrix(rows, columns, &A);

    // заполнение матрицы
    double arr[2][2] = {{1, 2}, {3, 4}};

    fill_matrix_from_array(&A, *arr, rows, columns);

    // обработка матрицы...

    // очистка памяти
    s21_remove_matrix(&A);
    return 0;
}
```

Компиляция приложения:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c s21_matrix.a -lm -o app
```

## Тестирование

Тесты написаны с использованием библиотеки **Check** и покрывают все операции, включая граничные случаи: NULL-указатели, матрицы 1х1, некорректные размеры, вырожденные матрицы.

```bash
make test
```

При успешном прохождении вы увидите отчет вида:

```text
100%: Checks: 50, Failures: 0, Errors: 0
```

## Покрытие кода

```bash
make gcov_report
```

Команда собирает проект с флагом `--coverage`, прогоняет тесты и генерирует
HTML-отчёт с помощью `lcov/genhtml`. Отчёт доступен по пути: `report/index.html`. Директория `report` создается автоматически и удаляется `make clean`.

## Стиль кода

Код отформатирован в стиле *Google C Style* с помощью `clang-format`.

```bash
make style          # Проверить форматирование (без изменений)
make fix-style      # Применить форматирование
```

## Требования

- **GCC** или **Clang** с поддержкой *С11*
- **GNU Make**
- **Check** — библиотека для unit-тестов
- **lcov** и **genhtml** — для отчета покрытия
- **clang-format** — для проверки стиля
